# Saarthi

Source-of-truth repo for personal Claude Code agent skills, subagents, and slash commands.

## Layout

```
skills/      Agent skills (each in its own dir with SKILL.md + supporting files)
agents/      Subagents (one .md file per agent)
commands/    Slash commands (one .md file per command)
```

## What's here

- `skills/find-skills/` — Anthropic-provided default for discovering skills.
- `skills/skill-creator/` — Anthropic-provided default for authoring/evaluating skills.
